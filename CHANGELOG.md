# Changelog

All notable changes to `squircle-ui` are tracked here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-05-17

First public release.

### Added
- Full `SKILL.md` covering `@squircle-js/react` API (`Squircle`, `StaticSquircle`, `asChild`).
- Recommended `cornerRadius` scale per element type (badge, button, card, avatar, hero, iOS app icon).
- Seven copy paste patterns: button, card, avatar, hero image, iOS app icon (60×60 r13), Framer Motion, manual double squircle border.
- Anti blob rule for elements under 32px.
- Common mistakes table.
- Explicit exceptions kept on plain CSS (`rounded-full`, micro UI).
- `npx skills add` install path verified end to end against the Vercel `skills` CLI.
- Banner.
